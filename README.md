# Basic Website Template (HTML & CSS)

A beginner-friendly template collection for learning HTML and CSS fundamentals. Each version includes heavily commented code and practical tips to guide new developers.

---

## 📋 Quick Start

### 1. Download the Template
To download a folder from GitHub, 
navigate to your desired repository, 
select the folder you want to download from GitHub, 
copy the URL, navigate to 
https://download-directory.github.io/
and paste the URL into the text box, and hit enter.

### 2. Set Up Your Project
```
My-Website/
├── index.html                    # Main page
├── EmptyPages/
│   └── EmptyPage1.html          # Additional pages
├── EmptyCss/
│   └── EmptyCss.css             # Stylesheet
├── EmptyFonts/                  # Your .ttf or .woff files
└── EmptyIllustrations/          # Images and icons
    └── Icon.png                 # Favicon
```

### 3. Update File Paths
- Replace `EmptyIllustrations/`, `EmptyFonts/`, etc. with your actual folder names
- Update all `href` and `src` attributes in HTML files
- Test locally by opening `index.html` in your browser

### 4. Customize
- Edit the HTML structure
- Update CSS colors, fonts, and layout
- Replace placeholder images and text

## ❓ FAQ

**Q: Can I use this commercially?**  
A: Yes! This template is open source. No attribution required, but appreciated.

**Q: My fonts aren't loading. What do I do?**  
A: Check that the font file path in CSS matches your folder structure. Use relative paths like `../EmptyFonts/FontName.ttf`. See the CSS comments for detailed guidance.

**Q: How do I make my site look good on mobile?**  
A: The template includes a `@media (max-width: 480px)` example. Customize the breakpoint for your needs and adjust the layout inside.

**Q: What's the difference between the versions?**  
A: V0.5 has the most comments and tips. V0.1-0.4 show earlier iterations. All are functional—choose V0.5 to start.
